Praktik Wajib Tugas XII

Panduan Git, GitHub & GitHub Pages

Dokumentasi langkah demi langkah sesuai ketentuan tugas informatika.

Langkah 1

VS Code & Struktur Folder

Membuat folder project terpisah untuk aset (gambar, css, js) dan file HTML utama (index.html, dll) lalu membukanya di Visual Studio Code.

Langkah 2

Git Add & Commit

Membuka terminal di VS Code, jalankan perintah git add . lalu git commit -m "inisialisasi portofolio ayah".

Langkah 3

Git Push ke GitHub

Menghubungkan repository lokal ke GitHub via remote origin dan melakukan git push -u origin main (Push = Komputer ke GitHub).

Langkah 4

Aktivasi GitHub Pages

Masuk ke menu Settings repository di GitHub, pilih tab Pages, lalu ubah Source ke main branch untuk mempublikasikan website secara online.

Langkah 5

Edit, Commit & Push Ulang

Melakukan perubahan kecil pada kode di VS Code, lalu ulangi proses git add ., commit, dan push untuk memperbarui live website.

Langkah 6

Konsep Push vs Pull

Push: Mengirim file dari Komputer ke GitHub.
Pull: Mengambil pembaharuan file dari GitHub ke Komputer.
